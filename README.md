# University Registration System

A Java-based University Registration System designed to manage students, courses, and their enrollments using fundamental data structures and algorithms.

## Overview

This project implements a university registration system where students and courses are managed through linked lists, while enrollment relationships are maintained between students and courses.

The system provides operations for adding and removing students and courses, managing enrollments, searching, sorting, and checking enrollment conditions.

## Features

- Add a new student
- Add a new course
- Remove a student
- Remove a course
- Enroll a student in a course
- Remove a student's enrollment from a course
- List courses enrolled by a student
- List students enrolled in a course
- Sort courses by Course ID for a specific student
- Sort students by Student ID for a specific course
- Check whether a course is full
- Check whether a student has normal enrollment
- Get the last student with an enrollment
- Get the last course with enrollments
- Undo enrollment operations
- Redo enrollment operations

## Data Structures & Algorithms

- Singly Linked Lists
- Stack
- Bubble Sort
- Insertion Sort
- Searching and traversal

- Data Structures and Algorithms
